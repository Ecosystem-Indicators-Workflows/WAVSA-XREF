# README - `./data/xrefdata/`

- `./data/xrefdata/` contains data that is *never* edited, any modified versions of those files, such as from data cleaning and processing (whether from hand-editing or programmatic manipulation), is to be written to `./data/processed_data/`.

Three versions of the WA cross-references by two interpreters (DAK and MGT) were shared by Mark Tozer on 12 Nov 2026.

From the file metadata:

> The pre-European vegetation mapping of Western Australia dataset is an output of a joint project. It maps original natural vegetation presumed to have existed prior to European settlement in Western Australia. Descriptions of each of the vegetation types can be found in the accompanying memoir.The major sources of data in this database are the published and unpublished mapping of J.S. Beard at 1:250,000 scale. There are c 30,000 polygons covering 160 1:250,000 map sheets.
